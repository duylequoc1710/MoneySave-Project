# 04 – Hướng dẫn cài đặt & sử dụng

## Chạy trên máy này (Mac)
```bash
cd "/Users/duyle/Sources/Vibe Coding/Projects/MoneyGo-Project/app"
npm run dev
```
Mở http://localhost:5173. Trong Chrome/Safari có thể “Cài đặt ứng dụng” để dùng như app Mac.

## Cài lên điện thoại (cần app được đưa lên một địa chỉ https – xem Roadmap mục Deploy)
- **iPhone/iPad**: mở bằng Safari → nút Chia sẻ → *Thêm vào MH chính*.
- **Android**: mở bằng Chrome → menu ⋮ → *Cài đặt ứng dụng*.
- **macOS**: Safari → Chia sẻ → *Thêm vào Dock*; hoặc Chrome → biểu tượng cài đặt trên thanh địa chỉ.

> Hiện tại (Giai đoạn 1) dữ liệu lưu riêng trên từng thiết bị. Đồng bộ giữa thiết bị là Giai đoạn 2.

## Sử dụng
- **Tổng quan**: số dư, biểu đồ đường Thu/Chi (6/12 tháng), nhóm chi nhiều nhất (đổi tháng bằng ‹ ›).
- **Sổ giao dịch**: ‹ › chuyển tháng (kể cả tương lai); chạm tên tháng để về tháng này; mỗi ngày có tổng ròng; chạm giao dịch để sửa/xoá; nút **+** để thêm.
- **Tài khoản**: tạo quỹ, tạo nhóm và gán vào quỹ, đặt ngân sách cho nhóm chi, sao lưu/khôi phục/xuất CSV.

## Lưu ý an toàn dữ liệu
Hãy bấm **Sao lưu (JSON)** định kỳ; iOS có thể xoá dữ liệu web nếu không dùng lâu.
